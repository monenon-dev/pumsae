## 3. 앱 콘텐츠 설문

### 앱 액세스 권한

**모든 기능을 이용하려면 로그인이 필요함**을 선택하고 심사용 계정을 적는다.

- 심사용 계정: 예시 데이터가 들어 있는 전용 계정을 따로 만들어 적는다(운영 계정 X).
- 안내 문구 예시: `이메일과 비밀번호로 로그인하면 모든 기능을 사용할 수 있습니다.`

### 광고

- 광고 포함: **아니요**

### 타겟층 및 콘텐츠

- 대상 연령: **18세 이상**만 선택(도장 운영자용 업무 앱).
- 아동에게 호소력이 있는가: **아니요**

### 콘텐츠 등급 (IARC 설문)

- 카테고리: **참고, 뉴스 또는 교육 이외의 앱 → 유틸리티, 생산성, 커뮤니케이션 또는 기타**
- 폭력, 성적 콘텐츠, 욕설, 약물·술·담배, 도박: 모두 **아니요**
- 사용자 간 상호작용·콘텐츠 교환: **예**
  - 도장이 올린 사진과 일정이 공개 홈페이지에 게시될 수 있음.
  - 사용자끼리 직접 메시지를 주고받는 기능은 없음.
- 사용자의 위치 정보 공유: **아니요**
- 디지털 상품 구매: **아니요**

예상 결과: 전체 이용가 또는 3세 이상(국가별로 다름).

|---|---|

**수집하는 데이터** (모두 "수집", "공유 안 함", "일시적 처리 아님")

| 데이터 유형 | 필수/선택 | 목적 |
|---|---|---|
| 개인 정보 → 이름 | 필수 | 앱 기능, 계정 관리 |
| 개인 정보 → 이메일 주소 | 필수 | 앱 기능, 계정 관리 |

| 기기 또는 기타 ID | 필수 | 앱 기능(푸시 알림 토큰) |

참고
- 학부모 연락처 등 체험 신청 정보는 **웹**에서 수집되고 앱은 서버에서 받아 **보여주기만** 하므로, 앱의 "수집" 항목에 넣지 않는다.
- 비밀번호는 로그인 확인에만 쓰고 앱에 저장하지 않는다(서버에는 bcrypt 해시만 저장).
- 분석, 광고, 위치, 연락처, 금융 정보는 수집하지 않는다.

## 5. 업로드 파일 만들기

```bash
cd pumsae_app
flutter build appbundle --release --dart-define=API_BASE_URL=https://pumsae-api.choseohee.com
# 결과: build/app/outputs/bundle/release/app-release.aab
```

- `android/key.properties`와 업로드 키(`pumsae-upload.jks`)가 있어야 업로드 키로 서명된다.
- 새 버전을 올릴 때마다 `pubspec.yaml`의 `version: 1.0.0+1`에서 `+` 뒤 숫자(versionCode)를 1씩 올린다.
- 첫 업로드 때 **Play 앱 서명**을 사용하도록 선택한다(업로드 키를 잃어도 재설정 가능).
