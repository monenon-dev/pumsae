# 지역 태권도장/체육관 맞춤형 홍보 & 수강생 관리 플랫폼 — 개발 가이드 v2

> 확정 스펙 기준으로 재작성. v1(디렉토리형 홍보 플랫폼)은 폐기하고 이 문서로 진행합니다.

## 0. 확정 스펙 요약

**핵심 기능 3가지**
1. **체육관 전용 홍보 랜딩페이지 빌더** — 관장님이 텍스트+사진만 입력하면 홍보 페이지 자동 생성
2. **인스타/포스터용 홍보 템플릿 생성기** — 대회 수상, 띠 승급, 신규 모집 카드뉴스를 웹에서 편집 후 이미지 다운로드
3. **입관 체험 신청 & 실시간 알림** — 학부모용 체험 신청 폼 + 관장님용 실시간 알림 대시보드

**기술 스택 (확정)**
| 영역 | 선택 |
|---|---|
| Frontend | Next.js 14 (App Router), TypeScript, Tailwind |
| DB + Auth + Storage + Realtime | **Supabase** (하나로 통합) |
| 고화질 이미지/PDF 변환 | Vercel Serverless Function + `puppeteer-core` (`@sparticuz/chromium`) |
| 빠른 클라이언트 미리보기 다운로드 | `html-to-image` (저해상도 즉시 다운로드용) |
| 배포 | Vercel |

**설계 포인트**
- WYSIWYG 템플릿 에디터: 텍스트/색상/폰트 변경이 Live Preview에 즉시 반영
- Mobile-First 반응형 (관장님이 이동 중 모바일로 작업)
- SEO + 동적 OG 이미지 생성 (SNS 공유 시 미리보기 최적화)

## 1. 데이터 모델 (Supabase 테이블 + RLS)

- **profiles** (Supabase auth.users 확장): id(=auth.uid), dojang_id(FK), name, role(OWNER/INSTRUCTOR)
- **dojangs**: id, name, slug(공개 URL용), region, address, phone, description, logo_url, hero_image_url, brand_color, created_at
- **promo_templates**: id, dojang_id(FK), type(AWARD/BELT_UP/RECRUIT/EVENT), content(jsonb: 텍스트·색상·폰트 값), thumbnail_url, created_at
- **trial_requests**: id, dojang_id(FK), student_name, parent_name, parent_phone, desired_class(KIDS/ELEMENTARY/MIDDLE_HIGH/ADULT), memo, status(PENDING/CONFIRMED/DECLINED), created_at

**RLS 정책 방향**
- `dojangs`, `promo_templates`: 소속 직원(`profiles.dojang_id` 일치)만 수정 가능, 조회는 `dojangs`/랜딩페이지 데이터는 공개(anon) 읽기 허용
- `trial_requests`: **insert는 익명(anon) 허용** (학부모가 로그인 없이 신청), **select/update는 해당 도장 소속 직원만**
- Realtime: `trial_requests`에 Postgres Changes 구독 → 관장님 대시보드에 새 신청 실시간 표시

## 3단계 — Supabase 테이블 & RLS 정책

이 단계는 Cursor보다 **Supabase SQL Editor**에서 직접 실행하는 게 안전합니다. Cursor에게 SQL을 생성시키고, 실행은 콘솔에서 확인 후 진행하세요.

### Cursor 프롬프트
```
Supabase Postgres용 SQL을 작성해줘. 아래 테이블과 RLS 정책을 만들어야 해.

테이블:
- profiles (id uuid PK references auth.users, dojang_id uuid, name text, role text check in ('OWNER','INSTRUCTOR'))
- dojangs (id uuid PK default gen_random_uuid(), name text, slug text unique, region text, address text, phone text, description text, logo_url text, hero_image_url text, brand_color text, created_at timestamptz default now())
- promo_templates (id uuid PK, dojang_id uuid references dojangs, type text, content jsonb, thumbnail_url text, created_at timestamptz default now())
- trial_requests (id uuid PK, dojang_id uuid references dojangs, student_name text, parent_name text, parent_phone text, desired_class text, memo text, status text default 'PENDING', created_at timestamptz default now())

RLS 정책:
- dojangs: 전체 SELECT는 anon/authenticated 모두 허용(공개 랜딩페이지용). INSERT/UPDATE는 본인 소속 도장만(profiles.dojang_id = dojangs.id AND auth.uid() = profiles.id) 가능하도록.
- promo_templates: SELECT/INSERT/UPDATE/DELETE 모두 소속 직원만.
- trial_requests: INSERT는 anon 역할도 허용(학부모용, dojang_id만 지정하면 됨). SELECT/UPDATE는 소속 직원만.
- profiles: 본인 행만 SELECT/UPDATE 가능.

각 정책에 주석으로 이유를 달아서 SQL 전체를 작성해줘. 실행은 내가 Supabase SQL Editor에서 직접 할 거야.
```

## 5단계 — 홍보 랜딩페이지 빌더

### Cursor 프롬프트
```
관장님이 텍스트/사진만 입력하면 자동으로 생성되는 홍보 랜딩페이지 기능을 만들어줘.

1. /app/dashboard/landing/page.tsx (관리 화면)

   - hero 섹션(대표 사진 + 이름 + 소개), 브랜드 컬러를 CSS 변수로 적용

   - 반 정보를 유치부·초중고 / 성인반 두 섹션으로 나눠서 보여줄 자리(placeholder)를 잡아줘 (실제 반 데이터는 이후 단계에서 연결)

Mobile-First로 작성하고, 미리보기 컴포넌트는 관리 화면과 공개 페이지에서 재사용 가능하게 분리해줘.
```

## 6단계 — 홍보 템플릿(카드뉴스) 생성기 — WYSIWYG 에디터

### Cursor 프롬프트
```
대회 수상, 띠 승급, 신규 모집 카드뉴스를 만드는 WYSIWYG 템플릿 에디터를 만들어줘.

1. /app/dashboard/templates/new/page.tsx
   - 템플릿 타입 선택(AWARD/BELT_UP/RECRUIT/EVENT)별로 미리 정의된 레이아웃 3~4종 제공
   - 좌측: 편집 패널 (제목, 부제목, 본문 텍스트, 배경색, 폰트 크기/굵기 선택)
   - 우측: Live Preview — 1080x1080 정사각형(인스타 포스트 비율) 카드 컴포넌트, 편집 패널 값이 바뀌면 즉시 반영
   - 상태는 React state(jsonb로 저장할 구조와 동일한 형태)로 관리

2. "빠른 다운로드" 버튼
   - `html-to-image` 라이브러리로 Preview DOM을 즉시 PNG로 캡처해서 다운로드 (저해상도, 클라이언트에서 바로 처리)

3. "저장" 버튼
   - content(jsonb)를 promo_templates 테이블에 저장

아직 고화질 다운로드(서버 렌더링)는 다음 단계에서 만들 거니까 이번 단계는 편집 UI + 즉시 미리보기 + 저해상도 다운로드까지만 구현해줘.
```

## 7단계 — 고화질 이미지/PDF 변환 (Vercel Serverless Function)

### Cursor 프롬프트
```
저장된 템플릿을 고화질 PNG 또는 PDF로 변환하는 서버리스 API를 만들어줘.

1. /app/api/templates/[id]/export/route.ts
   - puppeteer-core + @sparticuz/chromium 사용 (Vercel 서버리스 환경에서 동작하는 조합)
   - 쿼리 파라미터로 format(png|pdf) 받기
   - 처리 흐름:
     a. templateId로 promo_templates에서 content(jsonb) 조회
     b. 해당 content를 렌더링하는 내부 HTML 페이지(/app/render/template/[id]/page.tsx, 인증 불필요한 순수 렌더링 전용 라우트)를 만들어서
     c. puppeteer-core로 그 페이지를 방문 → 스크린샷(png) 또는 pdf() 생성
     d. 결과 바이너리를 응답으로 반환 (Content-Type 적절히 설정)

2. /app/render/template/[id]/page.tsx
   - 6단계에서 만든 카드 컴포넌트를 그대로 재사용해서, content(jsonb) 값으로 채워서 렌더링만 하는 페이지 (편집 UI 없음, 순수 출력용)

3. 대시보드 템플릿 상세 화면에 "고화질 다운로드(PNG)" / "PDF로 저장" 버튼 추가, 위 API 호출

puppeteer-core 관련 패키지 설치 명령어와 Vercel 배포 시 주의사항(번들 크기, @sparticuz/chromium 버전 호환)을 주석으로 남겨줘.
```

## 8단계 — 입관 체험 신청 & 실시간 알림

### Cursor 프롬프트
```
학부모용 체험 신청 폼과 관장님용 실시간 알림 대시보드를 만들어줘.

1. /components/TrialRequestForm.tsx
   - 학생 이름, 학부모 이름, 연락처, 희망 반(유치부/초등/중고등/성인), 메모 입력
   - anon 권한으로 trial_requests에 insert (RLS로 이미 허용된 상태)
   - 공개 랜딩페이지([slug]/page.tsx)의 "체험 신청하기" 버튼에 모달 또는 별도 섹션으로 연결

2. /app/dashboard/trials/page.tsx
   - 해당 도장의 trial_requests를 최신순으로 리스트
   - Supabase Realtime(postgres_changes)을 구독해서 새 신청이 오면 리스트 맨 위에 즉시 추가 + 알림 배지/토스트 표시
   - 각 항목에 상태 변경 버튼(PENDING → CONFIRMED/DECLINED)

3. Realtime 구독은 클라이언트 컴포넌트에서 useEffect로 supabase.channel(...)을 사용해서 구현해줘. 컴포넌트 언마운트 시 구독 해제도 잊지 말고 처리해줘.
```

## 10단계 — 배포

배포 자체는 Vercel-GitHub 연동으로 진행할 거니까 설정 파일과 안내만 준비해줘.

## 진행 순서 요약
1. 셋업 → 2. DB/RLS → 3. 인증 → 4. 랜딩페이지 빌더 → 5. 템플릿 에디터 → 6. 고화질 변환 → 7. 체험신청+실시간 알림 → 8. SEO/OG → 9. 배포

**우선순위 조언**: 포트폴리오 발표 임팩트 기준으로는 5단계(WYSIWYG 템플릿 에디터)와 7단계(실시간 알림)가 가장 시연 효과가 큽니다. 시간이 부족하면 9단계(SEO/OG)는 후순위로 미뤄도 핵심 기능 데모에는 지장 없습니다.
